# QQ 机器人指令速查

默认命令前缀是 `- `，可在 `xiaomiao/config.json` 的 `Others.reminder` 修改。私聊可以直接发送自然语言、图片、表情包或文件进入 Agent；群聊仍使用 `- 内容` 或 `@小喵 内容`。

## 基础

| 指令 | 说明 |
|------|------|
| `ping` | 测试机器人是否在线 |
| `- 帮助` | 查看 QQ 内置帮助 |
| `- 关于` | 查看机器人版本和信息 |
| `任意问题` | 私聊普通 AI 对话，进入 xiaomiaoAgent |
| `- 任意问题` | 群聊普通 AI 对话，进入 xiaomiaoAgent |
| `@小喵 任意问题` | 群聊中用 @ 方式对话 |

## Agent 能力

| 指令示例 | 说明 |
|----------|------|
| `- 记忆状态` | 查看 Agent 状态 |
| `- 整理记忆` | 触发记忆整理 |
| `- 记忆日志` | 查看记忆整理日志 |
| `恢复记忆` / `- 恢复记忆` | 恢复记忆版本；普通用户按低风险策略会被工具层拦截，白名单用户可直接执行 |
| `- 新会话` | 新建会话 |
| `- 停止任务` | 停止当前任务 |
| `抓取这个网页内容：https://example.com` | 私聊抓取公网网页正文并总结 |
| `- 抓取这个网页内容：https://example.com` | 群聊抓取公网网页正文并总结 |
| 私聊发送图片、表情包或文档后再提问 | 图片/表情包会转给 Agent，文档会保存到 `workspace/downloads/qq/`，可转 Markdown 和总结 |

普通用户可以直接用自然语言交给 Agent 处理任务，但只允许执行低风险工具，例如读取允许目录、搜索、抓取公网网页、转换文档和查询状态。

ROOT、Super 或 Agent 工具白名单用户会直接以 `trusted_confirmed` 工具策略进入 Agent，可执行本机命令、写文件、MCP 动作等高风险工具。

如果 Agent 任务超过 5 分钟还没有完成，QQ 会先提示：

```text
任务还在处理中，完成后会继续发给你。
```

任务不会因为这个提示被取消，完成后仍会继续返回结果。

## 图片和媒体

| 指令 | 说明 |
|------|------|
| `- 读图` | 切换到图片理解模式 |
| `- 大头照 @用户` | 获取指定用户头像 |
| `- 大头照` | 私聊或未 @ 时获取自己的头像 |
| `- 名言` 加引用消息 | 生成名言图片 |
| `生图` | 随机图片，群聊和私聊都可裸发 |
| `- 生图 白丝` | 按标签生成/搜索图片 |
| `- 生图 初音` | 常用角色标签 |
| `- 生图 横图` | 横向壁纸 |
| `- 生图 竖图` | 竖向壁纸 |
| `- 生图 安全` | 全年龄图片 |

## 管理指令

以下通常需要 Manage、Super 或 ROOT 权限。

| 指令 | 说明 |
|------|------|
| `- 感知` | 查看运行状态 |
| `- 注销` | 清空对话上下文 |
| `- 修改 HH:MM 内容` | 修改定时消息 |
| `- 核验 QQ号` | 查询 QQ 用户信息 |
| `- 禁言 @用户 秒数` | 禁言群成员 |
| `- 解禁 @用户` | 解除禁言 |
| `- 踢出 @用户` | 踢出群成员 |
| `撤回` 加引用消息 | 撤回被引用消息 |
| `- 重启` | 重启机器人 |

## 权限管理

以下通常需要 Super 或 ROOT 权限。

| 指令 | 说明 |
|------|------|
| `- 让我访问` | 查看当前权限用户 |
| `- 管理 M QQ号` | 添加 Manage_User |
| `- 管理 S QQ号` | 添加 Super_User |
| `- 删除管理 QQ号` | 删除用户管理权限 |
| `- 添加黑名单 群号` | 加入群发黑名单 |
| `- 删除黑名单 群号` | 移出群发黑名单 |
| `- 列出黑名单` | 查看黑名单 |

## 系统命令

| 指令 | 说明 |
|------|------|
| `- runcommand <命令>` | 旧本地系统命令入口，需要管理权限 |
| `- runcommand scheduled sends HH:MM 内容` | 设置定时发送 |
| `- runcommand message clear` | 清空本地上下文 |

建议优先用自然语言触发 Agent 工具链路，例如：

```text
帮我在本机执行 dir
```

白名单用户可直接执行高风险 Agent 工具；普通用户仍可执行低风险 Agent 任务，但不能升级到高风险工具。
