## 基础对话场景

### 场景 1: 日常问候

**用户操作**:
```
@小喵 你好
```

**Bot 回复**:
```
你好！我是小喵，有什么可以帮你的吗？😊
```

**说明**:
- 支持 @ 提及方式
- 自动识别问候语
- 友好的回复风格

---

### 场景 2: 无需 @ 的命令

**用户操作**:
```
帮助
```

**Bot 回复**:
```
🤖 小喵功能列表

💬 对话功能：
- @小喵 + 问题：与我聊天
- 搜索 + 关键词：搜索网络信息

📁 文件功能：
- 上传文件后我会自动处理
- 支持 PDF、Word、Excel、图片等

🎯 工具功能：
- 读图 + 图片：理解图片内容
- 生图 + 描述：AI 生成图片

⚙️ 管理功能：
- 帮助：显示此消息
- 关于：查看版本信息

更多功能请访问文档
```

**说明**:
- 精确匹配命令无需 @
- 支持命令：帮助、关于、读图
- 其他消息需要 @ 触发

### 场景 4: 知识问答

**用户操作**:
```
@小喵 Python 的列表推导式怎么用？
```

**Bot 回复**:
```
Python 列表推导式是一种简洁创建列表的方法：

📝 基本语法：
[表达式 for 变量 in 可迭代对象]

💡 示例：

# 生成 0-9 的平方
squares = [x**2 for x in range(10)]
# 结果：[0, 1, 4, 9, 16, 25, 36, 49, 64, 81]

# 过滤偶数
evens = [x for x in range(10) if x % 2 == 0]
# 结果：[0, 2, 4, 6, 8]

# 嵌套循环
pairs = [(x, y) for x in [1,2,3] for y in [3,4,5]]

🎯 优势：
- 代码更简洁
- 执行速度快
- 可读性好（简单场景）
```

**说明**:
- 直接回答编程问题
- 包含代码示例
- 清晰的格式化输出

### 场景 6: 图片理解

**用户操作**:
```
读图 [上传一张图片]
```

**Bot 回复**:
```
🖼️ 图片内容分析：

这是一张代码截图，显示的是 Python 代码：

代码内容：
- 定义了一个名为 calculate_sum 的函数
- 功能是计算列表中所有数字的和
- 使用了 sum() 内置函数

代码质量评估：
✅ 函数命名清晰
✅ 逻辑简洁正确
⚠️ 缺少类型注解
⚠️ 缺少文档字符串

建议改进：
def calculate_sum(numbers: list[int]) -> int:
    """计算数字列表的总和"""
    return sum(numbers)
```

**说明**:
- 精确匹配"读图"命令
- 支持代码、图表、场景等多种图片
- 提供详细分析和建议

### 场景 10: 高风险工具（需确认）

**用户操作** (ROOT 用户):
```
@小喵 帮我执行一个系统命令
```

**Bot 回复第一步**:
```
⚠️ 高风险操作需要确认

工具名称：execute_command
风险级别：高
需要权限：ROOT

操作说明：
- 此操作会执行系统命令
- 可能影响系统安全
- 建议谨慎使用

如需继续，请回复：
确认执行 [确认码：ABC123]

确认码 10 分钟内有效
```

**用户回复**:
```
确认执行 ABC123
```

**Bot 执行**:
```
✅ 确认码验证通过

⏳ 正在执行命令...

📤 执行结果：
[命令输出内容]

✅ 命令执行完成
```

**说明**:
- 高风险工具需要二次确认
- 生成随机确认码
- ROOT/Super/agent_tool_allowlist 用户才能触发
- 普通用户会被拒绝

## 最佳实践

### 1. 对话礼仪

**推荐**:
```
✅ @小喵 你好
✅ @小喵 帮我搜索一下 Python 教程
✅ 读图 [图片]
```

**不推荐**:
```
❌ 喂
❌ 在吗？（仅此一句，无具体问题）
❌ 一次发送大量消息刷屏
```

---

### 2. 文件上传

**推荐**:
```
✅ 上传文件后等待 Bot 自动处理
✅ 文件命名清晰（技术报告.pdf）
✅ 单次上传 1-2 个文件
```

**不推荐**:
```
❌ 同时上传大量文件
❌ 上传超大文件（>50MB）
❌ 上传无关文件（系统文件、病毒等）
```

---

### 3. 工具调用

**推荐**:
```
✅ 明确描述需求
✅ 提供必要的参数
✅ 高风险操作前确认
```

**不推荐**:
```
❌ 频繁调用高风险工具
❌ 恶意使用工具
❌ 忽略安全提示
```

---

### 4. 记忆管理

**推荐**:
```
✅ 定期整理记忆（每周一次）
✅ 新话题时创建新会话
✅ 重要信息明确告知
```

**不推荐**:
```
❌ 从不整理记忆
❌ 频繁创建新会话
❌ 期望 Bot 记住所有细节
```

## 常见问题

### Q1: Bot 没有响应？

**检查清单**:
1. 是否正确 @ 了 Bot
2. 命令是否需要 @（帮助、关于等不需要）
3. Bot 服务是否运行中
4. 是否在黑名单中

---

### Q2: 为什么我不能使用某些工具？

**原因**:
- 工具被分为低风险和高风险
- 普通用户只能使用低风险工具
- 高风险工具需要 ROOT/Super/白名单权限

**解决**:
- 联系管理员申请权限
- 使用替代的低风险工具

---

### Q3: 如何提高 Bot 回复质量？

**建议**:
1. 问题描述清晰具体
2. 提供必要的上下文
3. 定期整理记忆
4. 给予反馈（纠正错误回复）
