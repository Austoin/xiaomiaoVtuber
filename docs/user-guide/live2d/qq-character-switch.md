# QQ Bot 角色切换使用指南

> **更新时间**: 2026-06-13  
> **功能**: 在 QQ 中切换 AI 角色

---

## ✅ 可用命令

### 1. 查看角色列表

```
/角色列表
```

或者：
```
/角色
/characters
/chars
```

**返回示例**:
```
📋 可用角色列表：

✅ 当前 小喵 (xiaomiao)
     默认 AI 助手

   四季夏目 (natsume)
     高岭之花，外冷内热

   亚托莉 (atri)
     元气天使，天真烂漫

💡 使用方式：
   /切换 夏目
   /切换 亚托莉
```

### 2. 切换角色

```
/切换 夏目
/切换 亚托莉
/切换 小喵
```

或使用英文：
```
/switch natsume
/switch atri
/switch xiaomiao
```

**返回示例**:
```
✅ 已切换到 四季夏目

……嗯。我是夏目。
```

### 3. 查看当前角色

```
/当前角色
```

或者：
```
/current
/whoami
```

**返回示例**:
```
📌 当前角色：四季夏目 (natsume)

高岭之花，外冷内热
```

## 🎭 角色介绍

### 小喵 (xiaomiao) - 默认

**定位**: AI 助手，技术顾问型

**性格**:
- 智能、友好、专业、可靠
- 适度幽默，不过分活跃
- 尊重用户，保持适当距离

**适用场景**:
- 日常对话
- 技术支持
- 问题解答

**示例对话**:
```
用户: 你好
小喵: 你好！我是小喵，很高兴为你服务。有什么我可以帮你的吗？
```

### 四季夏目 (natsume) - AI 女友

**定位**: 高岭之花，外冷内热

**性格**:
- 安静寡言，但每句话都有分量
- 外冷内热，对你特别在意
- 四爱向（女攻男受），会主动关心
- 偶尔毒舌，但透着温柔

**适用场景**:
- 轻松对话
- 需要关心时
- 想要陪伴时

**示例对话**:
```
用户: 你好
夏目: ……嗯。

用户: 今天好累
夏目: 笨蛋，累了就休息。我陪着你。
```

### 亚托莉 (atri) - AI 女友

**定位**: 机器人少女，元气天使

**性格**:
- 天真烂漫，充满好奇
- 说话直接，元气满满
- 对主人忠诚温柔
- 偶尔天然呆，很可爱

**适用场景**:
- 需要元气时
- 想要活泼对话
- 心情低落时

**示例对话**:
```
用户: 你好
ATRI: 主人好！ATRI 来啦~ ✨

用户: 今天心情不好
ATRI: 诶？为什么心情不好？ATRI 可以帮忙吗？
```

## 🔧 技术实现

### 集成到 xiaomiao/main.py

在消息处理函数中添加：

```python
from xiaomiao.character_commands import handle_character_command, is_character_command

async def handle_message(event):
    message = event.get_plaintext()
    
    # 检查是否是角色命令
    if is_character_command(message):
        handled, reply = handle_character_command(message)
        if handled:
            await send_message(reply)
            return
    
    # 原有的消息处理逻辑
    ...
```

### 与 xiaomiaoAgent 集成

切换角色后，系统提示会自动更新：

```python
from tool.xiaomiao.character_manager import CharacterManager

# 获取当前角色的系统提示
character_prompt = CharacterManager.get_current_prompt()

# 发送给 Agent
system_message = f"""
{character_prompt}

[其他系统指令...]
"""
```

## ⚠️ 注意事项

1. **角色记忆独立**
   - 每个角色有独立的对话记忆
   - 切换角色不会带走之前的对话历史
   - 切回来会恢复该角色的记忆

2. **角色持久化**
   - 切换后的角色会保存到配置文件
   - 下次启动会使用上次选择的角色

3. **权限要求**
   - 所有用户都可以查看角色列表
   - 切换角色建议限制权限（可选）
