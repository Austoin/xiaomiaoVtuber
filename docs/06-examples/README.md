## 🎯 如何使用示例

### 1. 选择适合的示例
- 新用户 → 从配置示例开始
- API 开发者 → 查看 API 调用示例
- QQ Bot 用户 → 查看使用场景示例

### 2. 复制和修改
所有示例都可以直接复制使用，只需修改：
- API Keys
- QQ 号
- 服务地址
- 个性化配置

### 3. 验证和测试
使用示例后，运行验证命令确保配置正确：
```powershell
start-all.cmd --check
```
