# 操作文档

## 1. 环境要求

- Node.js：建议使用当前 LTS 版本。
- pnpm：项目声明版本为 `pnpm@10.33.0`。
- Git：用于版本管理；当前 `xiaomiaobot` 作为 `xiaomiaoVirtual` 子目录管理，不需要单独初始化仓库。

```powershell
corepack enable
corepack prepare pnpm@10.33.0 --activate
pnpm -v
```

## 2. 安装依赖

在项目根目录执行：

```powershell
pnpm install
```

## 3. Git 仓库说明

`xiaomiaobot` 当前不需要单独执行 `git init`。只有把它从 `xiaomiaoVirtual` 中独立抽出做上游开发时，才在独立目录执行：

```powershell
git init
git branch -M main
git add .
git commit -m "chore: initialize repository"
```

## 4. 上传到云端仓库

只有独立抽出 `xiaomiaobot` 时才需要上传单独远端。先在 GitHub、Gitee 或其他平台创建一个空仓库，不要勾选初始化 README。

把下面的地址替换成你的远端仓库地址：

```powershell
git remote add origin https://github.com/<你的账号>/<你的仓库>.git
git push -u origin main
```

如果使用 SSH 地址：

```powershell
git remote add origin git@github.com:<你的账号>/<你的仓库>.git
git push -u origin main
```

## 5. 常用启动指令

### 小喵统一 Agent 联动前置服务

如果要验证 `stage-web` 聊天、桌面端小喵回复表现或 QQ 普通 AI 回复，推荐从仓库根目录启动完整链路：

```powershell
cd F:\xiaomiaoVirtual
start-all.cmd
```

`start-all.cmd` 会串行启动必要服务。QQ/NapCat 登录窗口保持可见，其它服务窗口默认最小化；前一步未通过健康检查时，后续终端不会打开。

手动启动时，需要先启动后端链路：

```powershell
cd F:\xiaomiaoVirtual\xiaomiaoAgent
conda activate xiaomiao
python -m xiaomiao_agent serve --config F:\xiaomiaoVirtual\xiaomiaoAgent\.nanobot\config.json
```

然后启动 NapCat，并确认 OneBot WebSocket 是 `127.0.0.1:5004`。

再启动小喵：

```powershell
cd F:\xiaomiaoVirtual\xiaomiao
conda activate xiaomiao
python main.py
```

关键端口：

```text
5004  NapCat OneBot WebSocket
5519  xiaomiao 桥接服务
8765  xiaomiaoAgent 网关
8900  xiaomiaoAgent OpenAI 兼容 API
5174  xiaomiaoAgent WebUI
5175  xiaomiaobot stage-web
```

如果 `python main.py` 输出 bridge 地址后又报 OneBot WebSocket 断开，说明 NapCat 连接失败；主进程退出后 `5519` 也会消失。

QQ / Web / xiaomiaoAgent WebUI 共享 `xiaomiao-unified` 会话和桥接事件。QQ 本地命令 `帮助`、`关于`、`读图` 使用精确匹配，普通问题中包含这些词时仍作为 AI 请求进入 xiaomiaoAgent。

QQ 工具请求会经过权限网关：普通用户默认只能触发 `low_risk` 工具；ROOT/Super/`agent_tool_allowlist` 用户请求本机命令、MCP 动作或外部服务写操作时，会直接以 `trusted_confirmed` 策略执行。中文记忆命令包括 `记忆状态`、`整理记忆`、`记忆日志`、`恢复记忆`、`新会话`、`停止任务`。

### Web 版

```powershell
pnpm dev:web
```

等价于：

```powershell
pnpm -rF @proj-airi/stage-web run dev
```

`stage-web` 的文本输入、移动端输入和页面级录音转文字入口都会请求 `http://127.0.0.1:5519/v1/chat/completions`，再由小喵转发到 xiaomiaoAgent 的 `http://127.0.0.1:8900/v1/chat/completions`。桥接服务或 xiaomiaoAgent 不可用时，聊天历史会显示明确 error，不会静默回退。

### Web HTTPS 版

```powershell
pnpm dev:web:https
```

### 桌面 Electron 版

```powershell
pnpm dev:tamagotchi
```

等价于：

```powershell
pnpm -rF @proj-airi/stage-tamagotchi run dev
```

桌面端读取小喵桥接状态，将回复同步到字幕、聊天历史、TTS 和 Live2D 口型。Web 端通过桥接事件回放已确认消息，刷新后仍能看到三端同步记录。stage-pocket 移动端已接入第一批只读桥接事件同步，可展示聊天、工具、确认、记忆和舞台事件。

### 文档站

```powershell
pnpm dev:docs
```

### 服务端运行时

```powershell
pnpm dev:server
```

### 服务端 API

```powershell
pnpm -F @proj-airi/server dev
```

服务端 API 会读取 `apps/server/.env.local`。

## 9. 常见问题

### 远端已存在提交，push 失败

如果云端仓库不是空仓库，先确认是否要合并远端历史。

```powershell
git pull origin main --allow-unrelated-histories
git push -u origin main
```

### 修改远端地址

```powershell
git remote set-url origin https://github.com/<你的账号>/<你的仓库>.git
git remote -v
```

### 查看当前 Git 状态

```powershell
git status
git log --oneline --max-count=5
```
